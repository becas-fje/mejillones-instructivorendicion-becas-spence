---

## 🌐 Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub (por ejemplo, `instructivo-becas-mejillones`).
2. Sube **todos los archivos y carpetas** de este paquete al repositorio:
   - `index.html` (la guía — abre por defecto)
   - `assets/` (logos y capturas del formulario)
   - `fonts/` (tipografía Graphik)
   - `descargas/` (plantilla de Poder Simple para descargar)
3. En GitHub, ve a **Settings → Pages**.
4. En **Source**, elige **Deploy from a branch**, selecciona la rama `main` y la carpeta `/ (root)`.
5. Guarda. En 1–2 minutos tendrás una URL pública del tipo:
   `https://<tu-usuario>.github.io/<nombre-del-repo>/`
